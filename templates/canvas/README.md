# Canvas Starter Templates

These files are reference-quality starter patterns for `launchCanvas` artifacts.

- `chart.html` — compact bar chart with a PNG export button
- `form.html` — multi-field form with client-side validation
- `diff-viewer.html` — side-by-side before/after comparison
- `data-table.html` — searchable sortable table
- `dashboard.html` — static dashboard layout pattern

All templates are single-file, self-contained, mobile-friendly, and avoid external dependencies.
